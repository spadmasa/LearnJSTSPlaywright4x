00 · How the labs are organised

Every lab is a single runnable file: node <folder>/<file>.js. The number in the file name is the lab number, so lab 101_Fn.js is the 101st exercise. Files marked _IQ are interview drills; files marked REAL are QA-flavoured versions of the same idea. Several files deliberately contain code that throws — that is the lesson. Where a lab's comment mislabels a result, these notes give the correct one.

01 · Running code & the engine labs 1–4

Hello world and expressions

console.log("Hello World!");   // prints, then a newline
console.log(1 + 2);             // 3  — the expression is evaluated first
console.log(2 * 2);             // 4

console.log is your first debugger. With commas it inserts a space: console.log("a", 1) → a 1. With + it concatenates instead.

How Node runs a file

Node hands the file to V8. V8 parses the whole file first, compiles it to bytecode, runs it in the interpreter (Ignition), and recompiles "hot" code — a loop body that runs many times — into machine code (TurboFan). That is JIT compilation.

Consequence: one syntax error anywhere stops the file from running at all — even the console.log on line 1 never prints. A runtime error (e.g. calling an undefined function) only stops execution at that line, after earlier lines have already run.
let a = 10;
console.log(a);        // 10
// A commented-out 100,000-iteration loop in the lab shows "hot" code:
// the second time through, TurboFan may have compiled the loop body.
One-liner: JavaScript is parsed and compiled, not read line by line. Syntax errors are all-or-nothing; runtime errors happen where they happen.

Anatomy of a declaration

In let l = 10; → keyword let, identifier l, operator =, literal 10. A keyword is owned by the language and cannot be a name. An identifier is the name you choose.

Lab 5's rule of thumb for QA scripts: let ≈ 96%, const ≈ 3% (URLs, timeouts, config), var ≈ 1% (older code only).

Identifier rules

  1. First character: a letter, _ or $.
  2. Rest: letters, digits, _, $.
  3. Not a reserved word (class, let, if, return…).
  4. Case sensitive: Name and name are different variables.
var _ = 10;      var $ = 10;      var ab123 = 23;      // legal
let café = "ok"; let 变量 = "ok";  let \u0041 = "A";   // legal (Unicode letters, escapes)
// var 45 = 34;            SyntaxError: Unexpected number
// var my-name = "x";      SyntaxError: Unexpected token '-'
// var my name = "x";      SyntaxError: Unexpected identifier
// var class = "x";        SyntaxError: Unexpected reserved word
Trap: Function, String, Number are built-ins, not reserved words, so let Function = "x" runs — it simply shadows the global. Only true reserved words fail.

Boundary rule: age > 18 ? "Yes" : "No" says No for an 18-year-old. If 18 should pass, write age >= 18. That is boundary value analysis in one character.

06 · if/else and switch labs 46–58

Branches

if (age > 18) {
    console.log("Goa");
} else {
    console.log("No Goa");
}

// nested / else-if ladder — order matters, the first true branch wins
if (score > 100 || score < 0)      console.log("Invalid score");
else if (score > 90)                console.log("A");
else if (score > 80 && score <= 90) console.log("B");
else                                console.log("F");
Boundary bug in lab 49: the first check is score > 90, not >= 90, so 90 falls into band B. Always test the edges: 0, 49, 50, 60, 70, 80, 90, 100.

switch

switch (day) {
    case 1:  console.log("Mon"); break;
    case 2:  console.log("Tue"); break;
    default: console.log("unknown");
}
// without break, execution falls through into the next case (lab 51 prints 7 lines)
// grouped cases share one body (lab 54):
switch (browser) {
  case "Chrome": case "Edge": case "Brave": case "Opera":
      console.log("Chromium project"); break;
  case "Firefox": console.log("Mozilla"); break;
}
// switch(true) turns the cases into conditions (lab 56)
switch (true) {
  case (score >= 95): console.log("Outstanding"); break;
  case (score >= 85): console.log("Excellent");   break;
}
RuleDetail
Comparison is strictswitch uses ===: 0 matches case 0, never case false (lab 58)
DuplicatesTwo identical case labels are legal; the first match runs (lab 57)
default positionAnywhere, but it still runs last when nothing matches
Variables in a caselet inside a case is scoped to the whole switch block — wrap the case body in { } if you declare the same name twice
Choose: switch for one value against a fixed list (status codes, browser names); if/else for ranges and combined conditions; ternary when both branches only produce a value.

Transform

map ≠ forEach: map returns a new array, forEach returns undefined. for (let x in array) gives you the indexes as strings — a common interview mistake.

Sorting (the trap)

["banana","apple","cherry"].sort();     // alphabetical by default
[10,1,21,2].sort();                     // [1,10,2,21]  ← lexicographic, NOT numeric
[11,-11].sort();                        // [-11,11]     ("-" is 45, "1" is 49)
["banana","Apple"].sort();              // ["Apple","banana"] uppercase first

[10,1,21,2].sort((a,b) => a - b);       // [1,2,10,21]  ascending
[10,1,21,2].sort((a,b) => b - a);       // descending
["a","B"].sort((a,b) => a.localeCompare(b));   // human order, case aware

Default sort() converts to strings and compares character codes: digits 48–57, uppercase 65–90, lowercase 97–122. sort mutates the original array.

Slice, concat, copy, destructure

let arr = [1,2,3,4,5];
arr.slice(1,3);     // [2,3]  end exclusive, does not mutate
arr.slice(2);       // [3,4,5]
arr.slice(-2);      // [4,5]
arr.slice(-3,-5);   // []  — start 2 is after end 0; slice never reverses

[1,2].concat([3,4]);   // [1,2,3,4]
[...a, ...b];          // same thing, modern way

let copyShallow = [...arr];     // new array, one level
arr.slice();                    // also a shallow copy
let alias = arr;                // NOT a copy — same array

let [first, second] = [10,20];
let [a, b, ...rest] = [1,2,3,4,5];   // rest = [3,4,5]

Two lab comments to correct: in lab 97 let deep_copy_array = original; is not a deep copy — it is another name for the same array. For a real deep copy use structuredClone(original). In lab 100 the swap needs [p,q] = [q,p] as a statement (declare let p=1,q=2; first) — otherwise it is parsed as an array expression.
For testers: never mutate shared test data. const copy = [...base] for a flat array, structuredClone(base) when it holds objects.

11 · Closures lab 128

function startBrowser() {
    let name = "edge";                 // lives as long as the returned function
    function installBrowser() {
        console.log(name);
    }
    return installBrowser;
}
const runTc = startBrowser();
runTc();          // "edge" — the outer call has already finished

A closure is a function plus the scope it was created in. The inner function keeps name alive after startBrowser returns. That is how retry counters, memoisation and every Playwright fixture work.

Interview line: a closure lets a function remember variables from where it was defined, not where it is called.

20 · Encapsulation labs 188–194

class ICICI {
    #balance;
    constructor(name, balance) { this.#balance = balance; this.name = name; }

    getBalance() { return this.#balance; }

    setBalance(balance, isCashier) {          // validation lives here
        if (isCashier) this.#balance = balance;
        else console.log("Not allowed");
    }
}
let p = new ICICI("Pramod", 1000);
p.getBalance();                 // 1000
p.setBalance(10_000_000, false); // "Not allowed"
p.setBalance(300_000, true);     // allowed

Encapsulation = hidden state plus a controlled door. The # field cannot be touched from outside; every read and write goes through a method that can check, log, clamp or reject. Without #, obj.balance = 0 would silently corrupt the object.

Getters/setters alternative: get balance() { return this.#balance } lets callers write obj.balance while the validation still runs. Same idea, nicer call site.

Five-minute pre-interview sweep

  1. === always; know why "" == 0 is true and "" == "0" is false.
  2. typeof: null → object, NaN → number, [] → object, typeof typeof x → string.
  3. ++a changes then uses; a++ uses then changes. Trace two columns.
  4. Arrays: sort() is lexicographic; slice copies, splice mutates; map returns, forEach does not.
  5. Objects: = copies the reference; spread is shallow; structuredClone is deep.
  6. Hoisting: var → undefined, let/const → TDZ error.
  7. Async: async returns a promise; await unwraps; Promise.all fails fast; sequential vs parallel timing.
  8. OOP: extends + super, #private, static, no multiple inheritance without mixins.
